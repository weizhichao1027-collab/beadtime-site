隱私政策 · 拼豆時光

本政策說明拼豆時光實際上如何處理資料。App 已在 App Store 上架。它不收集資料，也不把內容發到開發者伺服器。

最近更新日期：2026年10月30日。本次補充 iPhone / iPad、產生偏好、暫存匯出、系統備份、網站託管與郵件支援說明。

我們收集什麼

開發者不從 App 收集照片、圖紙、材料清單、進度或使用紀錄。沒有帳號、廣告、分析 SDK、遠端當機回報、跨 App 追蹤或 App 自帶的雲端同步。隱私清單的收集資料類型為空。UserDefaults 在本機保存首次引導、語言偏好、上次產生的板尺寸、色數上限、品牌、細節模式與材料包裝數量偏好，不會傳送至開發者伺服器。

照片與相機

你主動選擇的相簿圖片、檔案，或用系統相機拍攝的圖片，只在裝置上用於產生拼豆圖紙。若開啟智慧移除背景，Apple Vision 在本機辨識並保護主體；照片和遮罩不會傳送給 Apple、開發者或任何伺服器。App 會在容器內儲存一份獨立壓縮預覽，便於繼續編輯和放入備份。

本地儲存與保留

項目、豆位、材料備齊狀態、跟拼進度與壓縮預覽保存在 App 容器，直到你刪除項目、刪除所有項目或移除 App。無效資料在本機隔離。你可匯出 JSON 備份、PNG 或 PDF。後續同類匯出時，App 會嘗試清理超過 24 小時的暫存分享副本，僅為此讀取 App 暫存目錄內的檔案修改時間。另存至其他位置的副本不受影響。系統備份（包括 iCloud 備份）可能依你的設定包含 App 資料；這與 App 雲端同步不同，開發者無法存取你的系統備份。

儲存到照片與分享

點選「儲存 PNG 到照片」時只申請新增照片權限，寫入所選匯出圖，不用於讀取相簿。其他主動匯出由系統分享面板與所選目標處理，目標服務可能依其政策處理檔案。系統備份也可能依你的設定保留 App 資料。

你的控制

你可只提供所選照片、刪除項目或所有本機項目，以及主動匯出備份。網站是唯讀靜態頁，不要求登入，也不設表單、分析、廣告或追蹤 Cookie。只有你主動寄信，支援信箱才會收到你提供的信箱地址、內文與附件以處理問題；這不是 App 自動收集。請避免寄送私人照片。

兒童與敏感資訊

App 不建設兒童帳戶，也不要求姓名、聯絡方式或其他敏感資訊。建議年齡分級為 4+，並可用於親子創作，但請不要匯入你不希望保留在本地項目中的照片。我們不面向收集兒童個人資訊。

第三方與伺服器

App 沒有第三方執行期 SDK，不連接開發者業務伺服器。背景移除使用 Apple Vision 在本機完成。網站託管於 GitHub Pages；託管方提供網頁時可能處理 IP 位址與基本請求紀錄，依其隱私說明辦理。網站自身不加入分析或廣告腳本。郵件由相關信箱服務商處理。
