製作步驟

把照片變成圖紙

在首頁選擇照片轉圖紙，用系統相簿、相機或檔案選圖。先調裁切、板尺寸、顏色上限、細節模式和參考色板。預設高品質路徑是 40×40、16 色。智慧背景移除保持關閉，除非主體清晰且背景干擾大。看即時預覽後產生，確認頁可對比原圖，或返回繼續調參。

統計材料並採購

打開材料頁查看每種顏色的顆數。勾選家裡已有的顏色，按包裝規格估算還缺幾包，再複製採購清單。螢幕色號是近似參考，大量購買前請對照品牌最新實物色卡。

依顏色跟拼

在跟拼裡選一個顏色，圖紙會只突顯該色。點選已放上的豆位記錄進度，查看總體完成度和下一個顏色。需要時打開螢幕常亮。進度保存在本機項目中。

匯出與備份

從工作區或項目選單匯出帶行列座標的 PNG 或 PDF。58×58 等大圖會帶 20×20 分區頁。換機或卸載前，到「我的 → 設定與隱私」匯出 JSON 備份。卸載會刪除沙盒裡的全部圖紙。

常見問題

照片會不會被上傳？

不會。你透過系統照片選擇器、相機或檔案提供的圖片，只在裝置上產生圖紙。智慧背景移除使用 Apple Vision 在本機工作，照片和遮罩都不會傳送到伺服器。

為什麼產生結果和我想的不一樣？

結果受原圖清晰度、裁切、板尺寸、顏色上限和細節模式影響。預設高品質路徑是 40×40、16 色。可先看即時預覽，產生後在確認頁對比原圖，或返回繼續調參。儲存後也能用原圖重新產生。

智慧背景移除怎麼用？

它預設關閉。打開後會在本機保護主體，並用連通背景判斷空豆位。若邊緣被切掉或背景仍在，關掉後再用手改空豆位，或換一張主體更清楚的照片。

色號能直接拿去買豆嗎？

色號是螢幕近似參考，不能當成廠商官方精確顏色。顯示器和材料批次都會有色差。大量採購前請對照品牌最新實物色卡。

匯出的 PNG 或 PDF 在哪裡？

從工作區或項目選單匯出。PNG 可儲存到照片（只申請加入權限，不會讀取圖庫）。PDF 可帶行列座標；58×58 等大圖會包含 20×20 分區頁。其他分享走系統分享面板。

項目找不到了或打不開？

資料在本機 Application Support/BeadTime。損壞項目會被隔離為 projects-invalid 檔案，其餘仍可打開。可先匯出備份。若提示庫檔案過大，原檔會被隔離且不會覆蓋。

備份如何匯入？

設定裡可匯出版本化 JSON 備份，再匯入合併。同一項目保留更新時間較新的版本。來自更新 App 版本的備份無法匯入。備份過大或項目過多也會被拒絕。

卸載後資料還在嗎？

不在。卸載會刪除沙盒裡的圖紙、預覽和跟拼進度。換機或刪除 App 前，請先匯出本地備份。

如何複製診斷資訊？

打開我的 → 設定與隱私 → 複製診斷資訊。內容包括 App 版本、裝置、系統和本地項目數，不含照片或圖紙。把它貼進支援郵件即可。

支援哪些語言？

英語、簡體中文、繁體中文、日語、韓語、西班牙語、法語、德語、巴西葡萄牙語、義大利語、俄語、阿拉伯語（從右到左）和印地語。可跟隨系統或在設定中固定。

相機權限用來做什麼？

僅在你選擇拍照產生圖紙時使用。照片同樣只在本機處理。App 不使用定位、麥克風、通訊錄或追蹤權限。

沒有網路能用嗎？

能。核心功能完全離線。打開本支援站或寄信才需要網路。App 本身不連接開發者伺服器。

App 是免費的嗎？

是。拼豆時光在 App Store 免費提供，沒有內購、訂閱或帳號。打開即可製作。

能在 iPad 或 Mac 上用嗎？

App 面向 iPhone，最低 iOS 17。App Store 發送未開放 iPad、Mac 或 Apple Vision Pro。請在 iPhone 上下載。
