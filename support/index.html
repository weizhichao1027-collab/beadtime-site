制作步骤

把照片变成图纸

在首页选择照片转图纸，用系统相册、相机或文件选图。先调裁切、板尺寸、颜色上限、细节模式和参考色板。默认高质量路径是 40×40、16 色。智能背景移除保持关闭，除非主体清晰且背景干扰大。看实时预览后生成，确认页可对比原图，或返回继续调参。

统计材料并采购

打开材料页查看每种颜色的颗数。勾选家里已有的颜色，按包装规格估算还缺几包，再复制采购清单。屏幕色号是近似参考，大量购买前请对照品牌最新实物色卡。

按颜色跟拼

在跟拼里选一个颜色，图纸会只高亮该色。点选已放上的豆位记录进度，查看总体完成度和下一颜色。需要时打开屏幕常亮。进度保存在本机项目中。

导出与备份

从工作区或项目菜单导出带行列坐标的 PNG 或 PDF。58×58 等大图会带 20×20 分区页。换机或卸载前，到「我的 → 设置与隐私」导出 JSON 备份。卸载会删除沙盒里的全部图纸。

常见问题

照片会不会被上传？

不会。你通过系统照片选择器、相机或文件提供的图片，只在设备上生成图纸。智能背景移除使用 Apple Vision 在本机工作，照片和遮罩都不会发送到服务器。

为什么生成结果和我想的不一样？

结果受原图清晰度、裁切、板尺寸、颜色上限和细节模式影响。默认高质量路径是 40×40、16 色。可先看实时预览，生成后在确认页对比原图，或返回继续调参。保存后也能用原图重新生成。

智能背景移除怎么用？

它默认关闭。打开后会在本机保护主体，并用连通背景判断空豆位。若边缘被切掉或背景仍在，关掉后再用手改空豆位，或换一张主体更清楚的照片。

色号能直接拿去买豆吗？

色号是屏幕近似参考，不能当成厂商官方精确颜色。显示器和材料批次都会有色差。大量采购前请对照品牌最新实物色卡。

导出的 PNG 或 PDF 在哪里？

从工作区或项目菜单导出。PNG 可保存到照片（只申请添加权限，不会读取图库）。PDF 可带行列坐标；58×58 等大图会包含 20×20 分区页。其他分享走系统分享面板。

项目找不到了或打不开？

数据在本机 Application Support/BeadTime。损坏项目会被隔离为 projects-invalid 文件，其余仍可打开。可先导出备份。若提示库文件过大，原文件会被隔离且不会覆盖。

备份如何导入？

设置里可导出版本化 JSON 备份，再导入合并。同一项目保留更新时间较新的版本。来自更新应用版本的备份无法导入。备份过大或项目过多也会被拒绝。

卸载后数据还在吗？

不在。卸载会删除沙盒里的图纸、预览和跟拼进度。换机或删除应用前，请先导出本地备份。

如何复制诊断信息？

打开我的 → 设置与隐私 → 复制诊断信息。内容包括 App 版本、设备、系统和本地项目数，不含照片或图纸。把它贴进支持邮件即可。

支持哪些语言？

英语、简体中文、繁体中文、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语、意大利语、俄语、阿拉伯语（从右到左）和印地语。可跟随系统或在设置中固定。

相机权限用来做什么？

仅在你选择拍照生成图纸时使用。照片同样只在本机处理。应用不使用定位、麦克风、通讯录或跟踪权限。

没有网络能用吗？

能。核心功能完全离线。打开本支持站或发邮件才需要网络。应用本身不连接开发者服务器。

应用是免费的吗？

是。拼豆时光在 App Store 免费提供，没有内购、订阅或账号。打开即可制作。

能在 iPad 或 Mac 上用吗？

应用面向 iPhone，最低 iOS 17。App Store 分发未开放 iPad、Mac 或 Apple Vision Pro。请在 iPhone 上下载。
