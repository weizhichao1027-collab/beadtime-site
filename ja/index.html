作り方

写真を図案にする

ホームで写真から図案を始め、写真、カメラ、またはファイルから画像を選びます。トリミング、プレートサイズ、色数、細部モード、参考パレットを決めます。丁寧な初期値は40×40、16色です。被写体がはっきりして背景が邪魔なとき以外、スマート背景除去はオフのままにしてください。ライブプレビューを見て生成し、元写真と比べるか、戻って調整します。

材料を数えて買う

材料画面で色ごとの個数を見ます。手元の色にチェックを付け、パック数を見積り、買い物リストをコピーします。画面の色番号は目安です。まとめて買う前にブランドの最新実物色見本を確認してください。

色ごとに作る

作り進めで1色を選ぶと、その色だけが強調されます。置いた粒をタップして進捗を記録し、全体の完了度と次の色を見ます。必要なら画面を常時点灯にできます。進捗はローカルプロジェクトに残ります。

書き出しとバックアップ

ワークスペースまたはプロジェクトメニューから、座標つきPNGまたはPDFを書き出します。58×58などの大きな図には20×20の分割ページが付きます。機種変更や削除の前に、「マイ → 設定とプライバシー」からJSONバックアップを書き出してください。アプリを削除するとサンドボックス内の図案はすべて消えます。

よくある質問

写真はアップロードされますか？

されません。システムの写真選択、カメラ、ファイルで選んだ画像は端末内だけで図案になります。スマート背景除去もApple Visionを端末内で使います。写真もマスクもサーバーへ送りません。

図案がイメージと違います。

元画像の鮮明さ、トリミング、プレートサイズ、色数、細部モードで結果が変わります。よく使う経路は40×40、16色です。ライブプレビューを見て、確認画面で元写真と比べるか、戻って調整してください。保存後も元画像から再生成できます。

スマート背景除去の使い方は？

初期状態はオフです。オンにすると端末内で被写体を守り、つながった背景を空マスにします。輪郭が欠けたり背景が残ったりしたらオフにして手で直し、または被写体がはっきりした写真に替えてください。

画面の色番号で買ってよいですか？

画面参考であり、工場の公式色ではありません。ディスプレイと材料ロットで差が出ます。まとめて買う前に最新の実物色見本を見てください。

PNGやPDFはどこに行きますか？

ワークスペースまたはプロジェクトメニューから書き出します。PNGは追加専用の写真権限で保存でき、その権限でライブラリは読みません。PDFには座標が付き、58×58など大きな図は20×20分割ページを含みます。ほかの共有はシステムの共有シートです。

プロジェクトが見つからない、開けない。

データは端末の Application Support/BeadTime にあります。壊れた項目は projects-invalid として隔離され、残りは開けます。先にバックアップを書き出してください。ライブラリが大きすぎる場合、元ファイルは退避され上書きされません。

バックアップの取り込み方は？

設定から版つきJSONを書き出し、マージで取り込みます。同じプロジェクトは更新日時が新しい方が残ります。より新しいアプリ版のバックアップは取り込めません。大きすぎるファイルや多すぎるプロジェクトも拒否されます。

削除しても図案は残りますか？

残りません。削除するとサンドボックスの図案、プレビュー、進捗が消えます。機種変更や削除の前にローカルバックアップを書き出してください。

診断情報のコピー方法は？

マイ → 設定とプライバシー → 診断情報をコピー。アプリ版、端末、システム、ローカルプロジェクト数が入ります。写真や図案は入りません。サポートメールに貼ってください。

対応言語は？

英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ブラジルポルトガル語、イタリア語、ロシア語、アラビア語（右から左）、ヒンディー語。システムに従うか、設定で固定できます。

カメラ許可は何のため？

図案用に撮影を選んだときだけ使います。その写真も端末内処理です。位置情報、マイク、連絡先、トラッキングは使いません。

オフラインで使えますか？

使えます。作る作業は完全オフラインです。このサイトを開くときとメール送信のときだけ通信が必要です。アプリは開発者サーバーに接続しません。

無料ですか？

無料です。App Storeで無料提供し、アプリ内課金、サブスクリプション、アカウントはありません。開けば作れます。

iPadやMacでも使えますか？

iPhone向けで、iOS 17以降です。iPad、Mac、Apple Vision Pro はストアの配信先になっていません。iPhoneで入手してください。
