アイデアをプレートへ

ビーズタイムは、アイロンビーズ図案のための完全オフラインなiPhoneアプリです。写真または内蔵図案を選び、この端末で編集できる図を作り、材料を揃えて色ごとに完成させます。

App Storeで入手 作り方を見る
アカウント不要 iOS 17以降 無料、アプリ内課金なし

このアプリは何か

ビーズタイムは Shanghai Qishan Cultural Communication Co., Ltd.（上海岐山文化伝播有限公司）のiPhoneアプリです。英語ストア名は Fuse Beads: Pattern Maker。Apple ID 6799906107。Bundle ID は com.weizhichao.beadday。写真アプリ・カメラ・ファイルの画像を、実物のプレートで作れる図案にします。オリジナル内蔵図案は24点。生成、編集、材料、作り進め、バックアップはすべて端末内です。データは収集せず、開発者サーバーにも接続せず、広告や解析SDKもありません。

アイロンできる図案から

プレートサイズ、色数上限、Perler / Hama / Artkal の参考パレットを選びます。色合わせは端末内の知覚色差で行い、輪郭を守ります。そのあと1粒ずつ直し、個数を確認し、色ごとに進捗を付けます。

一枚の写真から一枚のプレートへ

写真か内蔵図案から

システムの写真選択、カメラ、またはファイルから選べます。24点のオリジナル図案から始めることもできます。正方形トリミングは拡大と位置ずらしに対応。スマート背景除去は初期オフ。オンにするとApple Visionが端末内で被写体を守ります。

作れるところまで直す

色の付け替え、空マス消しゴム、最大30回のやり直し、拡大、行列ジャンプ。材料画面では個数、用意済みチェック、パック目安、買い物リストのコピーができます。

色ごとに進めて書き出す

1色だけ強調し、置いた粒をチェックし、全体進捗と次の色を見ます。座標つきPNGまたはPDFを書き出せます。大きな図は20×20の分割ページになります。完成写真もローカルプロジェクトに残せます。

実物プレートに合わせたサイズ

よく使う出発点は40×40、16色。小さなモチーフは15×15や21×21。長方形とカスタムサイズでは、トリミング枠がプレートに揃います。

言語はあなたに従う

画面、許可説明、法的文面はシステム言語に従うか、設定で固定できます。アラビア語は右から左です。このサイトは言語ごとに別アドレスを持ち、検索や引用に使えます。

このiPhoneに残る

収集しない
アカウント、広告、第三者の解析SDK、トラッキングはありません。写真やプロジェクトを開発者サーバーへ送りません。
端末内の作業
量子化、背景除去、プレビュー、バックアップはアプリ容器の中です。削除するとローカル図案も消えるので、先に設定からバックアップを書き出してください。
外に出すものは自分で決める
ファイルがアプリの外に出るのは、PNGを写真に保存したときか、共有シートで行き先を選んだときだけです。
